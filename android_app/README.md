# Android Image Uploader

This sample app demonstrates how to select an image and upload it to `https://en.zydiy.com/effectview?id=6412`.

## Building
1. Open the `android_app` directory in Android Studio.
2. Let Gradle sync and build the project.
3. Run the app on an Android device (e.g. Samsung S23).

## Usage
- Tap **Select Image** to pick a photo from the gallery.
- The app uploads the selected image using a multipart HTTP request.
